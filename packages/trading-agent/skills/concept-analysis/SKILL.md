# Concept Analysis Skill

A股概念股深度分析工具，解决两个核心问题：
1. **概念股真伪验证** — 某只股票是否真正受益于该概念？
2. **概念持续性分析** — 这个概念能炒多久？是长期主线还是短期脉冲？

## Prerequisites

### Python环境要求
```bash
pip install akshare pandas numpy
```

### 依赖检查
在执行分析前，先检查akshare是否已安装：
```bash
python -c "import akshare; print(akshare.__version__)"
```

如果未安装，提示用户安装：
```bash
pip install akshare
```

### 数据准备
概念股分析依赖以下本地数据库表，需先同步数据：
- `concept_stocks` — 概念成分股（通过 `--sync-concepts <概念名>` 或 `--sync-all-concepts` 同步）
- `klines` — K线数据（通过 `--sync-all-kline` 同步）
- `fundamentals` — 财务数据（通过 `--sync-all-fundamentals` 同步）
- `market_news` — 市场新闻（通过 `market_news_sync.py` 同步）
- `business_composition` — 主营构成（由 concept_stock_picker.py 自动缓存）

## When to Use

当用户请求以下操作时调用此skill：
- 分析某个概念的成分股质量（哪些是真正受益的，哪些是蹭概念的）
- 验证某只股票与某个概念的关联度
- 判断某个概念的炒作持续性（能否成为长期主线）
- 筛选"真概念+高持续性"的投资标的
- 评估当前热点概念的参与价值和风险

## Core Modules

### 1. Concept Stock Verification (概念股真伪验证)

基于主营收入占比验证概念股真伪，过滤"蹭概念"的股票。

**核心逻辑**：
1. 获取概念成分股列表
2. 逐一获取各公司主营构成（akshare `stock_zygc_em`）
3. 将主营分类名称与概念关键词匹配
4. 累加匹配项的收入占比
5. ≥30% 为真概念股，<30% 为伪概念股

**支持的25个概念**：
人工智能、新能源、芯片、机器人、生物医药、白酒、新能源汽车、5G、光伏、锂电池、充电桩、数据中心、医美、半导体设备、军工、跨境电商、游戏、智能驾驶、储能、氢能源、信创、元宇宙、碳中和、工业母机、预制菜

**对于未覆盖的概念**：
- 先尝试使用 `verify_concept_stocks` 工具，脚本会自动提取概念名称中的关键词进行匹配
- 若结果不理想，可基于成分股的基本面和业务描述进行人工判断

### 2. Concept Persistence Analysis (概念持续性分析)

通过五维评分体系判断概念炒作的可持续性。

**五维体系**：

| 维度 | 权重 | 数据源 | 评分逻辑 |
|------|------|--------|----------|
| **政策面** | 25% | `market_news` | 政策提及次数 + 正面支持信号 - 监管风险 |
| **新闻面** | 20% | `market_news` | 新闻数量趋势 + 情绪比例 + 热点子话题 |
| **资金面** | 20% | `klines` | 概念成分股换手率变化（相比前期） |
| **技术面** | 15% | `klines` | 成分股平均涨跌幅 + 上涨股票比例 |
| **基本面** | 20% | `fundamentals` | 营收增长 + 净利润增长 |

**评分等级**：
- **A (≥80)** — 强持续性，可作为中期主线配置
- **A- (70-79)** — 较强持续性，阶段性热点，可参与
- **B+ (60-69)** — 一般持续性，短期热点，注意节奏
- **B (50-59)** — 较弱持续性，脉冲行情，快进快出
- **C+ (40-49)** — 弱持续性，一日游风险较高
- **C (<40)** — 无持续性，纯概念炒作，建议回避

## Workflow 1: Concept Stock Verification (概念股真伪验证)

用户询问"某概念里哪些股票是真正受益的"时使用。

### Step 1: 获取概念成分股

```bash
# 使用 get_concept_stocks 工具获取成分股
# 参数：concept=概念名称
```

### Step 2: 验证主营占比

```bash
# 使用 verify_concept_stocks 工具验证
# 参数：concept=概念名称, minRevenueRatio=最低主营占比(默认30)

# 示例：验证人工智能概念股
{"concept": "人工智能", "minRevenueRatio": 30}
```

### Step 3: 呈现结果

**输出格式**：

```
【人工智能 — 概念股真伪验证】
共50只成分股，真概念股12只，伪概念股38只
验证标准：主营收入中与概念相关占比 ≥ 30%

真概念股 (12只)：
  300033 同花顺 — 主营占比 45.2% [人工智能软件(25.3%)、智能投顾(19.9%)]
  ...

伪概念股示例 (5只)：
  600519 贵州茅台 — 主营占比 0% (关联度低)
  ...
```

### Step 4: 深度分析真概念股（可选）

对筛选出的真概念股，进一步分析：
- `get_quote` 获取实时行情
- `get_fundamentals` 获取财务数据
- `get_kline` 获取K线走势
- `get_stock_news` 获取个股新闻

## Workflow 2: Concept Persistence Analysis (概念持续性分析)

用户询问"这个概念能持续多久""该不该参与这个概念"时使用。

### Step 1: 运行持续性分析

```bash
# 使用 analyze_concept_persistence 工具
# 参数：concept=概念名称, days=回溯天数(默认30)

# 示例：分析人工智能概念的持续性
{"concept": "人工智能", "days": 30}
```

### Step 2: 解读评分结果

**输出格式**：

```
【人工智能 — 概念持续性分析】
分析周期：近30天 | 成分股数：50只

综合评分：78.5/100  [等级：A-]
投资结论：较强持续性，阶段性热点，可参与

五维雷达图 (0-100)：
  政策面 ████████████████░░░░ 82.0
  新闻面 ██████████████░░░░░░ 71.5
  资金面 ███████████████░░░░░ 75.0
  技术面 ████████████████░░░░ 80.0
  基本面 ██████████████░░░░░░ 68.0

维度详解：
  政策面 (权重25%) — 得分 82.0 → 加权 20.50
  新闻面 (权重20%) — 得分 71.5 → 加权 14.30
  资金面 (权重20%) — 得分 75.0 → 加权 15.00
  技术面 (权重15%) — 得分 80.0 → 加权 12.00
  基本面 (权重20%) — 得分 68.0 → 加权 13.60
```

### Step 3: 给出投资建议

根据评分等级给出差异化建议：

| 等级 | 建议 |
|------|------|
| A/A- | 可积极参与，关注真概念股中的龙头 |
| B+/B | 短线参与，快进快出，设好止损 |
| B-及以下 | 回避或极小仓位试水 |

## Workflow 3: Comprehensive Concept Investment Decision (综合概念投资决策)

用户询问"这个概念值不值得投"时使用，综合前两个工作流。

### Step 1: 真伪验证

运行 `verify_concept_stocks`，筛选出真概念股。

### Step 2: 持续性分析

运行 `analyze_concept_persistence`，判断参与时机。

### Step 3: 交叉分析

根据两个维度的结果给出综合建议：

| 持续性 | 真概念股多 | 真概念股少 | 建议 |
|--------|-----------|-----------|------|
| **高 (A/A-)** | 长期主线 | 精选龙头 | 核心配置 |
| **中 (B+/B)** | 阶段性行情 | 短线龙头 | 灵活参与 |
| **低 (B-/C)** | 脉冲行情 | 纯炒作 | 回避 |

### Step 4: 输出标的列表

从真概念股中，结合以下因素精选3-5只标的：
- 主营占比最高（最纯正）
- 市值适中（流动性好）
- 技术面走势良好（MA多头排列）
- 近期无重大利空新闻

## Data Sources

### 主营构成数据
- **来源**：akshare `stock_zygc_em` API
- **更新频率**：季度（随财报发布）
- **缓存**：自动保存到 `business_composition` 表

### 概念成分股
- **来源**：本地 `concept_stocks` 表（JoinQuant/Eastmoney同步）
- **更新频率**：每日

### 新闻数据
- **来源**：本地 `market_news` 表
- **更新频率**：实时（财联社等）

### K线/财务数据
- **来源**：本地 `klines` / `fundamentals` 表
- **更新频率**：日/季度

## Error Handling

### akshare数据获取失败
- 检查网络连接
- 检查akshare版本：`python -c "import akshare; print(akshare.__version__)"`
- 某些股票可能因停牌或退市导致数据缺失

### 概念未在映射表中
- `concept_business_map.json` 覆盖25个热门概念
- 未覆盖的概念会使用概念名称本身作为关键词匹配
- 若匹配效果差，提示用户当前概念映射不完善

### 数据库缺少数据
- 概念成分股缺失 → 提示执行 `--sync-concepts <概念名>`
- K线/财务数据缺失 → 提示执行 `--sync-all-kline` / `--sync-all-fundamentals`
- 新闻数据缺失 → 提示执行 `market_news_sync.py`

## Best Practices

1. **先验证再分析**：先做真伪验证筛选真概念股，再做持续性分析判断时机
2. **结合市场情绪**：参考 `analyze_sentiment` 的市场情绪指数，情绪过热时谨慎追高
3. **关注政策信号**：政策面评分高的概念更值得长期跟踪
4. **动态跟踪**：概念持续性会随时间变化，建议定期重新评估
5. **风险提示**：所有分析基于公开数据，不构成投资建议

## Important Notes

- 主营占比阈值默认30%，用户可自定义。阈值越高，筛选越严格
- 伪概念股并非完全没有投资价值，部分股票可能因业务转型而受益
- 概念持续性评分反映的是历史数据趋势，不代表未来表现
- 五维评分中基本面权重仅20%，因为概念炒作往往提前于业绩兑现
