# 新闻分析技能 V2

## 技能概述

本技能基于 `news-search` 技能获取的财经新闻数据，进行深度分析和挖掘，帮助用户理解新闻背后的市场影响。V2版本重大升级：

- **全球市场覆盖**：不仅分析A股，还包括港股、美股及全球宏观新闻
- **行业正反双向分析**：正面/负面影响分别统计，清晰呈现多空博弈
- **影响持续性评估**：判断新闻是短期波动、中期趋势还是长期结构性影响
- **投资日历联动**：将新闻热点与未来即将发生的事件关联，提示提前反应机会

## 数据来源

- 新闻数据：通过 `news-search` 技能调用同花顺问财财经资讯搜索接口
- 投资日历：调用 `a-share-analysis` 技能的 `investment_calendar.py` 脚本
- 行业映射：内置A股行业关键词词典 + 海外市场关键词
- 个股识别：基于股票代码正则匹配 + 公司名称词典（含中概股、港股、美股）

## 功能特性

### 1. 全球市场新闻覆盖
搜索查询覆盖四大市场维度：
- **A股**：重大新闻、政策利好、行业动态、上市公司公告
- **港股**：市场动态、科技板块、恒生指数、中概股回归
- **美股**：市场动态、科技股、美联储政策、纳斯达克
- **全球宏观**：宏观经济、国际贸易、原油价格、黄金价格、汇率波动
- **热点主题**：人工智能、新能源、半导体芯片、医药生物

### 2. 行业正面/负面影响深度分析
- 对每个行业分别统计**正面新闻数**和**负面新闻数**
- 计算行业情感得分和多空方向（偏多/偏空/中性）
- 输出正面影响TOP5行业和负面影响TOP5行业
- 覆盖行业：计算机、电子、有色金属、电力设备、公用事业、银行、证券、医药生物、房地产等

### 3. 新闻影响持续性评估
基于关键词规则判断每篇新闻的影响时长：

| 持续性 | 时间范围 | 判断依据 |
|--------|----------|----------|
| **短期** | 1-3天 | 涨停/跌停、异动、反弹/回调、一日游、日内波动、技术指标 |
| **中期** | 1-4周 | 季报/中报/年报、业绩预告、政策落地、行业数据、季节性因素 |
| **长期** | 1月+ | 产业升级、技术变革、结构性改革、长期趋势、五年规划、人口结构 |

### 4. 投资日历联动分析
- 自动获取未来1-2个月的投资日历事件
- 将当前新闻热点与即将发生的事件关联
- 提示"该话题与XX事件相关，可能提前反应或持续发酵"
- 覆盖事件：WWDC、SNEC光伏展、618购物节、OPEC+会议、中央政治局会议等

### 5. 情感分析
- 基于情感词典和规则对每篇新闻进行正负面判断
- 计算整体市场情绪指数
- 识别极端情绪的新闻

### 6. 个股影响识别
- 提取A股6位股票代码
- 识别港股、美股、中概股代码
- 通过公司名称关键词匹配
- 统计个股被提及频率和关联度

### 7. 结构化报告输出
- 支持JSON和Markdown两种格式
- 包含市场概况、热点话题、行业分析、个股分析、投资日历关联、风险/机会提示
- 每篇文章标注：情感、影响级别、持续性、市场区域

## 使用方法

### 命令行调用

```bash
# 分析最近7天全球市场新闻（默认）
python scripts/news_analysis.py

# 分析最近3天
python scripts/news_analysis.py --days 3

# 分析指定主题
python scripts/news_analysis.py --topic "人工智能"

# 输出Markdown格式
python scripts/news_analysis.py --format markdown --output report.md

# 输出JSON格式
python scripts/news_analysis.py --format json --output report.json
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--days` | 分析最近多少天的新闻 | 7 |
| `--topic` | 指定分析主题 | None（全市场） |
| `--format` | 输出格式：json 或 markdown | json |
| `--output` | 输出文件路径 | stdout |
| `--min-articles` | 最少需要的新闻数量 | 10 |
| `--api-key` | iwencai API密钥 | 从环境变量读取 |

### Python API

```python
from scripts.news_analysis import NewsAnalyzer

analyzer = NewsAnalyzer()
report = analyzer.analyze_recent_news(days=7)
print(report)
```

## 输出报告结构

### Markdown报告章节

1. **市场概况**：整体情绪、情感得分、文章统计
2. **新闻来源分布**：A股/港股/美股/全球 各多少篇
3. **影响持续性分布**：短期/中期/长期 各多少篇
4. **日度分布**：按日期统计新闻密度
5. **热点话题 TOP10**：高频关键词（已过滤停用词）
6. **行业影响深度分析**：正面/负面分别统计
7. **热门个股**：提及次数、情感、得分
8. **投资日历关联事件**：与新闻热点相关的未来事件
9. **风险警示**：高负面情感文章
10. **机会提示**：高正面情感文章
11. **重点文章分析**：前10篇详细拆解

## 注意事项

1. **数据依赖**：本技能依赖 `news-search` 技能的API，需要配置 `IWENCAI_API_KEY`
2. **请求频率**：iwencai API有频率限制，批量查询（18个查询词）可能触发限流，脚本内置指数退避重试机制
3. **分析准确性**：情感分析和行业映射基于规则词典，可能存在误判
4. **时效性**：新闻分析结果具有时效性，建议定期更新
5. **个股识别**：提取的个股信息仅供参考，不构成投资建议
