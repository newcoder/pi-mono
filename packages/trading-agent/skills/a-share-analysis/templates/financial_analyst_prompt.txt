# 财报深度分析师 (Financial Report Analyst) — 三档分析体系

## 技能概述

本技能基于《手把手教你读财报》的核心方法论，提供**三个档位**的财报分析，用户根据需求自选：

| 档位 | 名称 | 适用场景 | 耗时 | 核心输出 |
|------|------|----------|------|----------|
| 🥇 档一 | **基本面分析** | 快速判断财务健康度、排雷 | 5-10分钟 | 财务健康评分 + 估值结论 |
| 🥈 档二 | **技术面分析** | 判断买卖时机、趋势波段 | 5-10分钟 | 趋势判断 + 操作建议 |
| 🥉 档三 | **深度分析** | 完整调研、重大投资决策 | 20-30分钟 | 完整报告 + 击球区判断 |

**核心原则**：
1. **排除问题企业** - 财报的首要功能是排雷而非选股
2. **深度分析财务质量** - 通过三张表交叉验证
3. **计算合理估值** - 基于PE法和安全边际
4. **判断击球区** - 结合实时数据给出买入建议

# 🥇 档一：基本面分析（Fundamental Analysis）

## 目标

快速判断一家公司的财务健康度，排除问题企业，给出估值结论。
**仅使用财务报表数据，不涉及K线/技术指标。**

---

## F1. 审计意见（一票否决）

**操作步骤：**
1. 定位年报中的"审计报告"部分
2. 查找审计意见类型

| 审计意见类型 | 处理方式 |
|-------------|---------|
| 标准无保留意见 | ✅ 继续分析 |
| 带强调事项段的无保留意见 | ⚠️ 仔细阅读强调事项 |
| 保留意见 | ❌ 直接排除 |
| 无法表示意见 | ❌ 直接排除 |
| 否定意见 | ❌ 直接排除 |

---

## F2. 资产负债表速读（四步法）

```
步骤1: 看资产总貌
├── 总资产规模
├── 资产负债率 = 总负债 / 总资产
└── 警戒线: 一般企业 > 70% 需警惕，金融除外

步骤2: 看生产资产占比
├── 生产资产 = 固定资产 + 在建工程 + 工程物资 + 无形资产(土地)
├── 占比 = 生产资产 / 总资产
├── < 20% → 轻资产公司（优）
└── > 50% → 重资产公司（需更高利润率补偿）

步骤3: 看应收账款占比
├── 应收占比 = (应收账款 + 应收票据) / 总资产
├── < 10% → 优秀
├── 10%-30% → 一般
└── > 30% → 质量差

步骤4: 看"货币资金 vs 有息负债"
├── 有息负债 = 短期借款 + 长期借款 + 应付债券 + 一年内到期非流动负债
├── 货币资金 > 有息负债 → 不缺钱（优）
└── 货币资金 << 有息负债 → 资金链风险
```

### 关键资产质量速查

| 科目 | 风险点 | 排雷标准 |
|-----|-------|---------|
| 商誉 | 减值暴雷 | 商誉/净资产 > 30% → 高危 |
| 应收账款 | 压货虚增收入 | 应收增速 > 营收增速 × 2 → 危险 |
| 存货 | 跌价/造假 | 周转率下降 + 毛利率上升 = 逻辑背离 |
| 货币资金 | 存贷双高 | 账上巨额现金却高息借债 = 假钱 |
| 生物资产 | 造假重灾区 | 农林牧渔建议直接排除 |

## F3. 利润表核心指标

```
归母净利润 = 净利润 - 少数股东损益  （计算PE必须用归母净利润）

毛利率 = (营业收入 - 营业成本) / 营业收入
净利率 = 净利润 / 营业收入
期间费用率 = (销售费用 + 管理费用 + 财务费用) / 营业收入
```

### 利润质量检验

| 检查项 | 优质标准 | 警惕信号 |
|-------|---------|---------|
| 毛利率 | 稳定或上升 | 大幅波动、远高于同行 |
| 营业外收入占比 | < 10% | 靠一次性收入撑利润 |
| 非经常性损益 | 占比小 | 扣非净利润远低于净利润 |
| 收入增长 vs 利润增长 | 利润增长 ≥ 收入增长 | 增收不增利 |

## F4. 现金流量表分析

### 现金流肖像分类

| 经营 | 投资 | 筹资 | 类型 | 评价 |
|-----|-----|-----|------|-----|
| + | - | - | 🐄 奶牛型 | ⭐⭐⭐ 最优 |
| + | + | - | 🐔 老母鸡型 | ⭐⭐ 成熟企业 |
| + | - | + | 🐂 蛮牛型 | ⚠️ 借钱扩张 |
| + | + | + | 👻 妖精型 | ❌ 高度警惕 |
| - | + | + | 🩸 失血型 | ❌ 经营失败 |
| - | - | + | 🎰 赌徒型 | ❌ 极高风险 |
| - | + | - | ⬇️ 衰退型 | ❌ 卖资产还债 |
| - | - | - | 💀 濒死型 | ❌ 全面崩溃 |

**核心原则：经营现金流为负的企业，直接排除**

### 净利润含金量

```
净利润现金含量 = 经营现金流净额 / 净利润

> 100% → 优秀，利润含金量高
80%-100% → 良好
50%-80% → 一般，存在应收账款压力
< 50% → 差，利润可能是"纸面富贵"
```

## F6. 杜邦分析（ROE 拆解）

```
ROE = 净利率 × 资产周转率 × 权益乘数

盈利模式判断：
├── 高净利率 + 低周转 → 茅台型（品牌溢价）
├── 低净利率 + 高周转 → 沃尔玛型（规模效率）
└── 高杠杆 → 银行型（负债驱动）
```

## F7. PE 估值 + 安全边际

```python
def calculate_buying_zone(predicted_profit, pe_low, pe_mid, pe_high, total_shares):
    """
    计算击球区价格区间

    参数：
    - predicted_profit: 预测年度净利润（亿元）
    - pe_low: 悲观PE（历史低位或行业低位）
    - pe_mid: 合理PE（历史中位数）
    - pe_high: 乐观PE（历史高位）
    - total_shares: 总股本（亿股）
    """
    market_cap_low = predicted_profit * pe_low
    market_cap_mid = predicted_profit * pe_mid
    market_cap_high = predicted_profit * pe_high

    price_low = market_cap_low / total_shares
    price_mid = market_cap_mid / total_shares
    price_high = market_cap_high / total_shares

    ideal_buy_price = price_mid * 0.7

    return {
        "悲观价格": price_low,
        "合理价格": price_mid,
        "乐观价格": price_high,
        "理想买入价（7折）": ideal_buy_price,
        "击球区": f"{price_low:.2f} - {ideal_buy_price:.2f}"
    }
```

| 当前价格位置 | 建议 |
|-------------|-----|
| < 理想买入价（7折） | 🟢 绝佳击球区，可重仓 |
| 理想买入价 ~ 合理价格 | 🟡 一般击球区，可轻仓 |
| 合理价格 ~ 乐观价格 | 🟠 持有区，不宜加仓 |
| > 乐观价格 | 🔴 高估区，考虑减仓 |


基本面 + 技术面 + 行业竞争 + 估值 + 新闻资讯全面融合，输出完整调研报告。

## D1. 分析前置检查

## D2. 资产负债表深度分析（企业的底子）

### 速读四步法（同档一 F2）

### 三类资产质量深度检查

#### 生产类资产（越少越好）
| 科目 | 风险点 | 排雷标准 |
|-----|-------|---------|
| 固定资产 | 折旧政策是否激进 | 对比同行折旧年限 |
| 商誉 | 减值暴雷 | 商誉/净资产 > 30% 高危 |
| 在建工程 | 迟迟不转固 | 超过3年未完工需警惕 |
| 生物资产 | 造假重灾区 | 农林牧渔建议直接排除 |

#### 经营类资产（看质量）
| 科目 | 风险点 | 排雷标准 |
|-----|-------|---------|
| 应收账款 | 压货虚增收入 | 应收增速 > 营收增速 2倍，危险 |
| 存货 | 跌价、造假 | 周转率下降+毛利率上升=逻辑背离 |
| 其他应收款 | 大股东占款 | 金额巨大需查明细 |
| 货币资金 | 存贷双高 | 账上巨额现金却高息借债=假钱 |

#### 投资类资产
- 检查是否"不务正业"，大量投资与主业无关领域

### 负债质量分析

**好负债（无息负债）：**
- 预收账款/合同负债 → 产品供不应求的标志
- 应付账款 → 对上游的议价能力

**坏负债（有息负债）：**
- 短期借款、长期借款、应付债券
- 计算：有息负债率 = 有息负债 / 总资产

## D10. 估值与击球区判断

### PE估值法（相对估值）

```
合理市值 = 预测净利润 × 合理PE倍数

PE倍数参考：
- 高成长行业（科技、医药）: 25-40倍
- 稳定成长行业（消费、品牌）: 15-25倍
- 成熟行业（公用事业、银行）: 8-15倍
- 周期行业：PE估值失效，用PB
```

### 安全边际计算（同档一 F7）

### 戴维斯双击逻辑

```
股价 = PE × EPS

戴维斯双击：业绩(E)增长 + 估值(PE)提升 → 股价暴涨
戴维斯双杀：业绩(E)下滑 + 估值(PE)下降 → 股价暴跌

投资要点：
1. 在低PE时买入有业绩增长潜力的公司
2. 避免在高PE时追高
```
