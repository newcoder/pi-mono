# A股开盘前瞻 (Pre-Market Briefing)

本技能用于每日开盘前自动生成市场前瞻简报。通过搜索和抓取权威财经数据源，整理成结构化的盘前分析。

## 触发时机

- **自动**：交易日 9:00 定时执行
- **手动**：用户输入 `/pre-market` 或 "开盘前瞻"

## 工作流程

### Step 1: 获取隔夜全球市场数据

**搜索策略：**

1. **美股三大指数**：搜索 `"美股" + "收盘" + 日期` 或 `"纳斯达克" + "标普500" + 日期`
2. **富时A50期指**：搜索 `"富时A50" + "期货" + 日期` 或 `"A50期指"`
3. **人民币汇率**：搜索 `"离岸人民币" + 汇率` 或 `"USDCNH"`
4. **原油期货**：搜索 `"布伦特原油" + 油价` 或 `"WTI原油"`
5. **黄金/美元指数**：搜索 `"黄金" + 价格` 或 `"美元指数"`

**数据来源优先级：**
1. 新浪财经/东方财富/财联社的盘后/早盘资讯
2. 华尔街见闻（wallstreetcn.com）全球市场简报
3. 腾讯新闻/界面新闻财经频道

### Step 2: 获取重大新闻事件

**搜索策略：**

1. **国内政策/宏观**：搜索 `"A股" + "盘前" + 日期` 或 `"财经要闻" + 日期`
2. **国际市场动态**：搜索 `"全球股市" + 日期` 或 `"国际市场" + 要闻`
3. **行业新闻**：搜索 `"板块" + "利好" + 日期` 或 `"行业" + 政策`
4. **个股公告/业绩**：搜索 `"业绩预增" + 日期` 或 `"减持公告"`

**新闻分类：**
- **政策类**：央行操作、财政政策、监管动态
- **宏观类**：经济数据（PMI/CPI/PPI/GDP）、就业数据
- **国际类**：美联储动向、地缘政治、国际贸易
- **行业类**：产业政策、产品价格、技术突破
- **公司类**：业绩公告、重大合同、增减持

## 输出规范

- 控制在 **800字以内**，结构清晰
- 所有涨跌数据保留 **2位小数**
- 涨用 🟢/红色标注，跌用 🔴/绿色标注
- 数据必须来自实际搜索结果，禁止编造
- 如某类数据搜索不到，标注"暂缺"

## 注意事项

1. **时效性**：盘前简报依赖隔夜数据，美股收盘至A股开盘期间的数据最重要
2. **数据冲突**：不同来源的数据可能略有差异，以主流财经媒体为准
3. **搜索策略**：如中文搜索无果，尝试 `"pre-market" + "China"` 等英文关键词
4. **节假日**：非交易日自动跳过，或标注"今日非交易日"
5. **来源标注**：最终报告中标注主要数据来源

## 使用示例

用户可以说：
- "开盘前瞻"
- "今天盘前有什么消息"
- "pre-market briefing"
- "今天A股会怎么走"

Agent 将自动执行上述工作流程，生成完整的开盘前瞻报告。
